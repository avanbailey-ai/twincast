The workflow

  1. Capture: verified 18+ model records a guided phone scan; ID + live selfie match.
  2. Build: twin built only from that model’s consented scan.
  3. Generate: brand garment placed on the twin across chosen sizes.
  4. Approve: model approves every image before brand use — no approval, no license.
  5. License: 6-month Shopify / organic social / email use (US), rights certificate per image; model is paid per license.
